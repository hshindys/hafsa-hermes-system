## 1. كيف يعمل هرمز (Hermes Agent) — البنية الحالية

### ما هو هرمز؟
هرمز هو وكيل ذكاء اصطناعي مفتوح المصدر من **Nous Research**. مش مجرد شات بوت — ده وكيل مستقل بيشتغل على جهازك وبيقدر يتفاعل مع نظام الملفات، الإنترنت، الأوامر، وغيرها.

### المميزات الأساسية:
- **التعلم الذاتي عبر المهارات (Skills):** بيحفظ الإجراءات المتكررة كملفات مهارات بتتحمل في كل جلسة
- **ذاكرة دائمة:** بيفتكر المستخدم وتفضيلاته عبر الجلسات المختلفة
- **متعدد المنصات:** بيشتغل على Telegram, Discord, Slack, WhatsApp, Signal, Email وغيرها
- **مزود محايد:** بيشتغل مع أي مزود نماذج (OpenRouter, Anthropic, OpenAI, DeepSeek, إلخ)
- **ملفات تعريف (Profiles):** تقدر تشغل نسخ مستقلة بمهارات وإعدادات مختلفة

### البنية المعمارية الحالية عندك:
```
الجهاز (Linux FC44)
├── Hermes Gateway (الملف الشخصي: hafsa) ← أنا (حفصة)
│   ├── متصل بـ Discord (#حفصة)
│   ├── أدوات: terminal, file, browser, memory, skills, إلخ
│   └── MCP Servers: ginny_voice, hatem_nad, mem0, najati, sqlite
│
├── Hermes Dashboard (واجهة ويب)
│
└── Lola Bot (بوت Discord مستقل)
    ├── Python script منفصل
    ├── يستخدم نفس الـ Proxy (127.0.0.1:8645)
    └── يستخدم نفس النموذج (openrouter/owl-alpha)
```

## 2. كيف يعمل لولا بجانب حفصة؟

### الوضع الحالي:
- **حفصة (Hermes):** وكيل كامل القدرات — عنده وصول للملفات، الأوامر، الإنترنت، الذاكرة، المهارات
- **لولا (Lola):** بوت Discord مستقل — بتتكلم مع المستخدمين عبر Discord بس

### النقطة المهمة:
الاتنين بيشتغلوا على **نفس الجهاز** وبيستخدموا **نفس الـ Proxy** (127.0.0.1:8645) ونفس النموذج (openrouter/owl-alpha). ده ممكن يسبب:
- **تنافس على الموارد:** لو الاتنين شغالين في نفس الوقت، ممكن يبطأوا بعض
- **تنافس على الـ API:** نفس المفتاح بيستخدمه الاتنين
- **مشكلة JSON parse error:** اللي ظهرت في لوغ لولا — ممكن تكون بسبب الـ proxy مشغول

### مشكلة لولا الحالية:
```
[ERROR] JSON parse error: Expecting value: line 1 column 1 (char 0)
```
ده معناه إن لولا بتستقبل رد فاضي من الـ API. الأسباب المحتملة:
1. الـ Proxy مشغول بطلب من حفصة
2. الـ API key وصل للحد الأقصى
3. مشكلة في الـ timeout

## 3. هل ممكن يكون في نسختين هرمز على نفس الجهاز؟

### الإجابة: أيوه، وبجد!

هرمز بيدعم الـ **Profiles** بشكل أصلي. كل profile بيكون:
- إعدادات مستقلة (`~/.hermes/profiles/<name>/config.yaml`)
- جلسات مستقلة
- مهارات مستقلة
- ذاكرة مستقلة

### الطرق المتاحة:

**أ) Profiles (الطريقة الرسمية):**
```bash
hermes profile create <اسم_الجديد>
hermes --profile <اسم_الجديد> gateway run
```

**ب) نسخ مستقلة تمامًا:**
```bash
# نسخة ثانية بدليل مختلف
HERMES_HOME=C:/Users/hshin/.hermes2 hermes gateway run
```

**ج) عبر tmux (لجلسات تفاعلية):**
```bash
tmux new-session -d -s agent2 'hermes --profile agent2'
```

### التوصية:
استخدم **Profiles** — أسهل في الإدارة وأقل في استهلاك الموارد.

## 5. كيف نحسن الأداء — التوصيات

### أ) تحسين الوضع الحالي (حفصة + لولا):

**1. فصل الـ API Keys:**
```
حفصة: OPENROUTER_API_KEY=key1
لولا: OPENROUTER_API_KEY=key2 (لو مفتاح تاني متاح)
```
ده بيقلل التنافس على الـ API

**2. فصل الـ Proxy:**
```
حفصة: proxy على port 8645
لولا: proxy على port 8646
```

**3. إصلاح مشكلة JSON parse error في لولا:**
- تأكد إن الـ proxy مش مشغول
- زود الـ timeout
- أضف retry logic

**4. تحسين الـ Model:**
- أنت حالياً تستخدم `stepfun/step-3.7-flash:free` كـ default
- ولولا تستخدم `openrouter/owl-alpha`
- يفضل توحد النموذج أو تستخدم نماذج مختلفة لكل وكيل

### ب) تحسين هرمز نفسه:

**1. تفعيل الـ Memory Provider:**
```bash
hermes config set memory.provider honcho
```
ده بيحسن الذاكرة بشكل كبير

**2. تحسين الـ Compression:**
```bash
hermes config set compression.threshold 0.60
```
بيحسن استخدام السياق

**3. تفعيل الـ Checkpoints:**
```bash
hermes config set checkpoints.enabled true
```
بيحمي من فقدان البيانات

**4. إضافة MCP Servers مفيدة:**
- أنت عندك 5 MCP servers بالفعل — ده ممتاز
- ممكن تضيف MCP servers للبحث أو لقواعد بيانات

### ج) لو عايز تضيف وكيل تالث:

**الخيار 1: Profile جديد في هرمز**
```bash
hermes profile create agent3
# عدل الإعدادات
hermes --profile agent3 gateway run
```

**الخيار 2: إطار عمل مختلف (CrewAI)**
```bash
pip install crewai
# أنشئ فريق من الوكلاء
```

**الخيار 3: استخدام Kanban في هرمز**
- هرمز عنده نظام Kanban مدمج
- بيسمح بتنسيق العمل بين الوكلاء المختلفين

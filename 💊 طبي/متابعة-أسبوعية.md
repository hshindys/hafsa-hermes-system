# 📊 المتابعة الأسبوعية — وزن / ضغط / سكر

> سجّل قياساتك كل أسبوع (يفضل يوم جمعة صباحاً قبل الأدوية).
> الهدف: مراقبة استقرار السكر والضغط وتتبّع الوزن.

## 🎯 النطاقات المستهدفة (تأكد مع طبيبك)
| القياس | المستهدف | ملاحظة |
|--------|----------|---------|
| الضغط الانقباضي | < 130 | أقل من 130/80 مثالي لمرضى سكري+ضغط |
| الضغط الانبساطي | < 80 | |
| سكر الصائم | 80–130 mg/dL | قبل الأكل |
| سكر بعد الأكل بساعتين | < 180 mg/dL | |
| الوزن | ثبات ±2kg | نزول تدريجي أفضل لو زائد |

## 🔴 متى تكشف طبيبك فوراً
- ضغط مستمر > 140/90
- سكر صائم متكرر > 180 أو أعراض ارتفاع/انخفاض
- صداع مفاجئ / دوخة / تغيّر بصري (تحذير الورم الدماغي)
- نزول وزن حاد بدون سبب

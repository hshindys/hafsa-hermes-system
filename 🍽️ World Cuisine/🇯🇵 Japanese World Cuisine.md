# 🇯🇵 المطبخ الياباني — صحي ومتوازن

> 🛑 **تذكير:** ممنوع لحاتم السمك والجمبري — استبدلي بالتوفو أو الدجاج

---

## 1. 🍲 Tofu Teriyaki (توفو تيرياكي)
- **السعرات:** ~250
- **الوقت:** 20 دقيقة
- **مناسب لل:** السكري، القلب (أوميجا 3 من الصويا)

### المقادير:
| الكمية | المكون |
|--------|--------|
| 300g | توفو صلب |
| 2 ملعقة | صويا صوص قليلة الملح |
| 1 ملعقة | عسل (أو ستيفا) |
| 1 ملعقة | زنجبيل مبشور |
| 1 | ثوم |
| 1 ملعقة | زيت سمسم |
| بصل أخضر | مفروم |
| سمسم | محمص |

### الطريقة:
1. قطعي التوفو مكعبات، اعصريها من الماء (مهم!)
2. سخني الزيت وحمري التوفو 5 دقائق لكل جنب
3. اخلطي الصويا + العسل + الزنجبيل + الثوم → صوص التيرياكي
4. ضيفي الصوص على التوفو وقلبي 2 دقائق
5. زيني بالسمسم والبصل الأخضر

## 2. 🥢 Miso Soup with Tofu (حساء ميسو بالتوفو)
- **السعرات:** ~120
- **الوقت:** 10 دقائق
- **مناسب لل:** الهضم، الضغط

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500ml | ماء + داشي نباتي (بلا سمك!) |
| 2 ملعقة | معجون ميسو |
| 200g | توفو مكعبات |
| 1 | أعشاب واكاميه (اختياري) |
| 2 | بصل أخضر مقطع |

### الطريقة:
1. اغلي الماء مع الواكاميه
2. ضيفي التوفو واتركيه دقيقتين
3. ضيفي الميسو (مهم: ممنوع تغلي بعد ما حطيتي الميسو!)
4. زيني بالبصل الأخضر

---

## 3. 🍱 Bento Bowl (صندوق بنتو صحي)
- **السعرات:** ~400
- **الوقت:** 30 دقيقة
- **مناسب لل:** متوازن، غداء كامل

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 كوب | أرز بني |
| 150g | دجاج مشوي مقطع |
| 1 | بيض مسلوق |
| نصف | أفوكادو |
| 1 كوب | خضار مشكلة (جزر، بروكلي، فاصوليا) |
| صوص | صويا + ليمون |

### الطريقة:
1. أكل الأرز البني
2. تبلي الدجاج واشويه
3. اسلقي البيض
4. حطي كل حاجة في صندوق مرتب

---

## 4. 🥬 Vegetable Stir Fry Asian (خضار مقلي على الطريقة الآسيوية)
- **السعرات:** ~150
- **الوقت:** 15 دقيقة
- **مناسب لل:** القلب، السكري

### المقادير:
| الكمية | المكون |
|--------|--------|
| بروكلي | ملصوق |
| فطر | 200g |
| جزر | مبشور |
| فلفل ألوان | شرائح |
| زيت سمسم | 1 ملعقة |
| ثوم | 2 |
| زنجبيل | 1 ملعقة |
| صويا صوص | 2 ملعقة |
| كاري (اختياري) | رشة |

### الطريقة:
1. سخني زيت الصيت في المقلاة على نار عالية
2. ضيفي الثوم والزنجبيل
3. ضيفي الخضار بالترتيب: الجزر → البروكلي → الفلفل
4. قلبي 5-7 دقائق (الخضار يبقى مقرمش)
5. ضيفي الصويا وقلبي دقيقة

---

## 5. 🍳 Okonomiyaki (أوكونوميياكي) بالسبانخ والدجاج
- **السعرات:** ~300
- **الوقت:** 25 دقيقة
- **مناسب لل:** غداء مشبع

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 كوب | دقيق قمح كامل |
| 1 | بيض |
| 2 ملعقة | صويا صوص |
| 200g | سبانخ مقطعة |
| 100g | دجاج مفروم |
| 1 | بصلة مفرومة |
| ثوم | 2 |
| زيت | قليل |

### الطريقة:
1. اخلطي الدقيق + البيض + 200ml ماء + الصويا → عجينة
2. ضيفي السبانخ + الدجاج + البصلة + الثوم
3. اقلي دوائر صغيرة في مقلاة 3 دقائق لكل جنب
4. قدميها مع صوص صويا + ليمون

---

## 💡 نصائح الياباني:

- ✅ الأرز البني بدل الأبيض
- ✅ البخار هو الأساس (صحي جداً)
- ✅ التوفو بديل ممتاز للسمك
- ✅ الصويا قليلة الملح
- ❌ ممنوع: أي صوص فيه داشي سمك (استبدليه بداشي نباتي)

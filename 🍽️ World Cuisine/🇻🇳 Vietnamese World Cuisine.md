# 🇻🇳 المطبخ الفيتنامي — طازج وصحي

> 🛑 **تذكير:** ممنوع لحاتم أي أكل بحري

---

## 1. 🍲 Pho (فو — شوربة فيتنامية)
- **السعرات:** ~280
- **الوقت:** 30 دقيقة
- **مناسب لل:** المناعة، الهضم

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500ml | مرق دجاج صافي |
| 200g | نودلز أرز |
| 100g | دجاج أو توفو |
| بهارات | نجمة أنيس، قرفة، زنجبيل، كركم |
| نباتات طازجة | كزبرة، بصل أخضر، فلفل حار، ريحان |
| ليمون | 1 |

### الطريقة:
1. اغلي المرق مع البهارات 15 دقيقة
2. اسلقي النودلز 3 دقائق
3. رتبي: نودلز → دجاج → مرق → نباتات طازجة
4. اعصري ليمون

---

## 2. 🥬 Fresh Spring Rolls (رولز طازج — بدون قلي)
- **السعرات:** ~120
- **الوقت:** 15 دقيقة
- **مناسب لل:** السكري، قليل السعرات

### المقادير:
| الكمية | المكون |
|--------|--------|
| ورق أرز | 6 |
| خس |  |
| جزر | مبشور |
| نعناع | طازج |
| كزبرة | طازج |
| دجاج مسلوق | 100g (اختياري) |
| صوص | صويا + ليمون + عسل |

### الطريقة:
1. بلل ورق الأرز
2. حطي الخضار والنباتات
3. لفيهم ورولز
4. قدمي مع صوص

---

## 3. 🥗 Vietnamese Salad (سلطة فيتنامية)
- **السعرات:** ~150
- **الوقت:** 10 دقائق

### المقادير:
ملفوف + جزر + خيار + نعناع + كزبرة + فلفل حار + ليمون + صويا + عسل

---

## 4. 🍜 Bún Chả (بون تشا — بدون سمك)
- **السعرات:** ~320
- **الوقت:** 25 دقيقة

### المقادير:
نودلز أرز + دجاج مشوي + خضار + نباتات + صوص صويا

### الطريقة:
1. اشوي الدجاج
2. اسلقي النودلز
3. رتبي كل حاجة

---

## 5. 🥬 Vegetable Stir Fry Vietnamese (خضار مقلي فيتنامي)
- **السعرات:** ~150
- **الوقت:** 15 دقيقة

خضار + ثوم + صويا + فلفل + ليمون

---

## 💡 نصائح الفيتنامي:
- ✅ الطازج هو الأساس (أعشاب، خضار)
- ✅ قليل الزيت
- ❌ ممنوع: صوص السمك — استبدليه بالصويا

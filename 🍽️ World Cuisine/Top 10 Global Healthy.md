# 🎯 تلخيص المطابخ العالمية — إيه الأكل الصحي في كل مطبخ؟

---

## 🥇 أفضل 5 مطابخ صحية في العالم

| الترتيب | المطبخ | السبب | الأكل المفضل |
|---------|--------|-------|-------------|
| 🥇 1 | 🇬🇷 اليوناني |  Mediterranean diet — زيت زيتون + خضار | Greek Salad, Lemon Soup |
| 🥈 2 | 🇯🇵 الياباني | قليل الدسم، بروتين نظيف | Tofu Teriyaki, Miso Soup |

## 🍳 أسهل 3 وصفات في كل مطبخ (5-15 دقيقة)

### 🇬🇷 اليوناني (10 دقائق)
1. Greek Salad → خس + طماطم + خيار + زيت زيتون
2. Hummus → حمص + طحينة + ثوم + ليمون
3. Tzatziki → زبادي + خيار + ثوم

### 🇯🇵 الياباني (15 دقيقة)
1. Miso Soup → ماء + ميسو + توفو + واكاميه
2. Onigiri → أرز + صويا + أي حشوة
3. Teriyaki Tofu → توفو + صويا + عسل

### 🇮🇹 الإيطالي (15 دقيقة)
1. Caprese → طماطم + موزاريلا + ريحان
2. Minestrone → خضار + مرق + لوبيا
3. Zucchini Noodles → كوسا + بيستو

### 🇲🇦 المغربي (15 دقيقة)
1. Fattoush → خضار + خبز محمص + سماق
2. Lentil Soup → عدس + بصل + بهارات
3. Roasted Veggies → خضار + بهارات + زيت

### 🇮🇳 الهندي (15 دقيقة)
1. Chana Masala → حمص + طماطم + بهارات
2. Palak Dal → عدس + سبانخ
3. Cucumber Raita → زبادي + خيار + كمون

### 🇪🇬 المصري (15 دقيقة)
1. Fattoush → خضار + خبز + صوص
2. Eggah → بيض + خضار
3. Molokhia → ملوخية + ثوم + كزبرة

### 🇲🇽 المكسيكي (15 دقيقة)
1. Black Bean Tacos → فول + أفوكادو + خس
2. Guacamole → أفوكادو + طماطم + ليمون
3. Quesadilla → دجاج + جبن + خضار

### 🇹🇭 التايلاندي (15 دقيقة)
1. Fresh Spring Rolls → خضار + ورق أرز + صويا
2. Green Curry → خضار + كريمة جوز الهند
3. Stir Fry → خضار + صويا + فلفل حار

### 🇰🇷 الكوري (15 دقيقة)
1. Kimchi Stew → كيمتشي + توفو + مرق
2. Japchae → نودلز + خضار
3. Bibimbap → أرز + خضار + بيض

### 🇨🇳 الصيني (15 دقيقة)
1. Stir Fry → دجاج + خضار + صويا
2. Fried Rice → أرز بني + بيض + خضار
3. Lettuce Wraps → دجاج + خس

### 🇱🇧 اللبناني (15 دقيقة)
1. Tabbouleh → برغل + بقدونس + ليمون
2. Hummus → حمص + طحينة
3. Fattoush → خضار + خبز محمص

### 🇹🇷 التركي (15 دقيقة)
1. Mercimek Çorbası → عدس + طماطم + بصل
2. Cacık → زبادي + خيار + ثوم
3. Köfte → لحم مفروم + بهارات + مشوي

### 🇪🇳 الإسباني (15 دقيقة)
1. Gazpacho → طماطم + خيار + فلفل + زيت
2. Tortilla Española → بيض + بطاطس
3. Ensalada de Pimientos → فلفل مشوي + زيت

### 🇫🇷 الفرنسي (15 دقائق)
1. Salade Niçoise → خس + بيض + طماطم
2. Soupe aux Lentilles → عدس + خضار
3. Chicken Herbs → دجاج + أعشاب

### 🇻🇳 الفيتنامي (15 دقائق)
1. Fresh Spring Rolls → خضار + نباتات
2. Pho Noodles → نودلز + مرق + نباتات
3. Bún Chả → نودلز + دجاج مشوي + خضار

## 🛑 الممنوع لحاتم 🚫

- ❌ السمك بجميع أنواعه
- ❌ الجمبري (الروبيان)
- ❌ الكابوريا (السلطعون)
- ❌ المحار
- ❌ أي حيوان بحري
- ❌ صوص السمك (fish sauce) → استبدل بالصويا
- ❌ مرق بحري → استبدل بمرق دجاج
- ❌ داشي سمك → استبدل بداشي نباتي

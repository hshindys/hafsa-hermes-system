# 🇪🇬 المطبخ المصري — صحي وبسيط

> 🛑 **تذكير:** ممنوع لحاتم أي أكل بحري

---

## 1. 🥬 Molokhia (ملوخية بالفراخ — قليلة الزيت)
- **السعرات:** ~200
- **الوقت:** 25 دقيقة
- **مناسب لل:** الهضم، فقر الدم

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500g | ملوخية خضراء |
| 2 | صدور فراخ |
| 4 | ثوم |
| كزبرة | يابسة + طازجة |
| مرق فراخ | 500ml |
| زيت زيتون | 1 ملعقة |
| ملح | قليل |

### الطريقة:
1. اسلقي الفراخ في مرق مع بهارات
2. حمري الثوم والكزبرة اليابسة
3. ضيفي الملوخية 10 دقائق
4. قدمي مع أرز بني أو خبز بلدي

---

## 2. 🍆 Bamia (بامية — نسخة صحية)
- **السعرات:** ~250
- **الوقت:** 30 دقيقة
- **مناسب لل:** الألياف، السكري

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500g | بامية |
| 200g | لحم مفروم (أو دجاج) |
| طماطم | 3 |
| بصلة | 1 |
| ثوم | 3 |
| بهارات | كمون، فلفل، قرفة |
| زيت زيتون | 1 ملعقة |

### الطريقة:
1. اغسلي البامية وقطعيها
2. حمري البصل والثوم
3. ضيفي اللحم وقلبي
4. ضيفي البامية والطماطم
5. سيبيها 20 دقيقة على نار هادية

---

## 3. 🥗 Fattoush (فتوش)
- **السعرات:** ~150
- **الوقت:** 10 دقائق
- **مناسب لل:** السكري، الضغط

### المقادير:
| الكمية | المكون |
|--------|--------|
| خس | مقطع |
| طماطم | مكعبات |
| خيار | شرائح |
| فجل | شرائح |
| بصل أخضر | مفروم |
| بقدونس + نعناع | طازج |
| خبز عربي | محمص |
| صوص | زيت زيتون + ليمون + سماق |

### الطريقة:
1. قطعي الخضار صغيرة
2. حمصي الخبز
3. اخلطي الصوص مع الخضار
4. ضيفي الخبز فوق قبل التقديم

---

## 4. 🍳 Eggah with Vegetables (عجة بالخضار)
- **السعرات:** ~180
- **الوقت:** 15 دقيقة
- **مناسب لل:** فطور صحي، بناء العضلات

### المقادير:
| الكمية | المكون |
|--------|--------|
| 4 | بيض |
| بصل | مفروم |
| طماطم | مقطعة |
| فلفل أخضر | مقطع |
| بقدونس | طازج |
| زيت زيتون | 1 ملعقة |
| ملح + فلفل | حسب الرغبة |

### الطريقة:
1. اخفقي البيض مع الخضار
2. سخني الزيت في المقلاة
3. ضيفي الخليط واتركيها 5 دقائق
4. اقلبيها واتركيها 3 دقائق تانية

---

## 5. 🍚 Egyptian Rice with Vermicelli (أرز مصري بالمكرونة)
- **السعرات:** ~280
- **الوقت:** 20 دقيقة
- **مناسب لل:** طاقة، طبق جانبي

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 كوب | أرز مصري |
| كوب | مكرونة رفيعة (شعيرية) |
| 2 ملعقة | زيت زيتون |
| 1.5 كوب | ماء ساخن |
| ملح | قليل |

### الطريقة:
1. حمري المكرونة في الزيت (ذهبي!)
2. ضيفي الأرز وقلبي دقيقة
3. ضيفي الماء والملح
4. سيبيها هادية 15 دقيقة
5. قدميها مع أي طبق رئيسي

---

## 6. 🍆 Mahshi (محشي — خضار محشوة)
- **السعرات:** ~220
- **الوقت:** 45 دقيقة
- **مناسب لل:** السكري، الألياف

### المقادير:
| الكمية | المكون |
|--------|--------|
| كوسا / باذنجان / فلفل | 6 حبات |
| أرز | 1 كوب |
| لحم مفروم (اختياري) | 100g |
| طماطم | 2 |
| بصل | 1 |
| ثوم | 3 |
| بهارات | كمون، فلفل، نعناع |
| زيت زيتون | 2 ملعقة |

### الطريقة:
1. فري الخضار من جوا
2. اخلطي الأرز + اللحم + البهارات + الطماطم
3. احشي الخضار
4. رتيها في صينية مع مرق
5. اخبزي 30 دقيقة 180°C

---

## 💡 نصائح المصري الصحي:

- ✅ قلل الزيت في الطبخ
- ✅ استخدم الفرن بدل القلي (المحشي بالفرن ممتاز)
- ✅ الأرز البني بدل الأبيض
- ✅ الخضار الطازجة يومياً
- ❌ ممنوع: أي أكل بحري (حتى السمسم في بعض الأطباق — استبدليه)

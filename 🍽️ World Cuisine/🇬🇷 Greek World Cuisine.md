# 🇬🇷 المطبخ اليوناني — متوسطي وصحي

> 🛑 **تذكير:** ممنوع لحاتم أي أكل بحري

---

## 1. 🥗 Greek Salad with Halloumi (سلطة يونانية مع حلوم)
- **السعرات:** ~220
- **الوقت:** 10 دقائق
- **مناسب لل:** السكري، الضغط

### المقادير:
| الكمية | المكون |
|--------|--------|
| خس | مقطع |
| طماطم | مكعبات |
| خيار | شرائح |
| بصل أحمر | شرائح رفيعة |
| زيتون أسود | 10 |
| 100g | جبن حلوم مشوية |
| صوص | زيت زيتون + ليمون + أوريجانو |

### الطريقة:
1. قطعي الخضار
2. اشوي الحلوم 3 دقائق لكل جنب
3. رتبي الخضار والحلوم فوق
4. رشي الصوص

---

## 2. 🍲 Lemon Chicken Soup (حساء الدجاج بالليمون)
- **السعرات:** ~200
- **الوقت:** 25 دقيقة
- **مناسب لل:** المناعة، البرد

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500ml | مرق دجاج |
| 2 | صدور دجاج مفرومة |
| 1 كوب | أرز (أو أورز) |
| 2 | بيض |
| عصير | 2 ليمون |
| بقدونس | طازج |

### الطريقة:
1. اغلي المرق مع الأرز 15 دقيقة
2. ضيفي الدجاج 10 دقائق
3. اخفقي البيض مع الليمون
4. ضيفيهم للمرق مع التقليب المستمر
5. زيني بالبقدونس

---

## 3. 🍆 Moussaka (موساكا — نسخة صحية)
- **السعرات:** ~280
- **الوقت:** 45 دقيقة
- **مناسب لل:** السكري، القلب

### المقادير:
| الكمية | المكون |
|--------|--------|
| 2 | باذنجان |
| 300g | لحم مفروم (أو دجاج) |
| بصلة | 1 |
| طماطم | 3 |
| ثوم | 3 |
| بهارات | كمون، فلفل، قرفة |
| بشاميل | دقيق + حليب + زبدة قليلة |

### الطريقة:
1. قطعي الباذنجان واخبزي 15 دقيقة
2. حمري البصل واللحم
3. ضيفي الطماطم والبهارات
4. رتبي: باذنجان → لحم → بشاميل
5. اخبزي 30 دقيقة

---

## 4. 🫘 Gigantes Plaki (فاصوليا بيضاء بالطماطم)
- **السعرات:** ~200
- **الوقت:** 30 دقيقة
- **مناسب لل:** السكري، النباتيين

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 علبة | فاصوليا بيضاء |
| 3 | طماطم |
| بصلة | 1 |
| ثوم | 3 |
| بقدونس | طازج |
| زيت زيتون | 2 ملعقة |

### الطريقة:
1. حمري البصل والثوم
2. ضيفي الطماطم والفاصوليا
3. اغلي 20 دقيقة
4. زيني بالبقدونس

---

## 5. 🥙 Pita Bread with Hummus (خبز عربي بالحمص)
- **السعرات:** ~250
- **الوقت:** 5 دقائق
- **مناسب لل:** فطور صحي

### المقادير:
خبز عربي محمص + حمص + زيت زيتون + ليمون + خضار

### الطريقة:
1. حمصي الخبز
2. افتحي الحمص مع زيت زيتون وليمون
3. قدمي مع خضار طازجة

---

## 💡 نصائح اليوناني:

- ✅ زيت زيتون هو الأساس
- ✅ الخضار طازجة يومياً
- ✅ الجبن بكميات معقولة
- ❌ ممنوع: أي سمك مشوي يوناني

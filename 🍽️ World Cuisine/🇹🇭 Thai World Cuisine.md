# 🇹🇭 المطبخ التايلاندي — حار ومتوازن

> 🛑 **تذكير:** ممنوع لحاتم السمك والجمبري — استبدلي بالتوفو أو الدجاج

---

## 1. 🍜 Pad Thai صحي (بالتوفو أو الدجاج)
- **السعرات:** ~320
- **الوقت:** 20 دقيقة
- **مناسب لل:** متوازن

### المقادير:
| الكمية | المكون |
|--------|--------|
| 200g | نودلز أرز |
| 200g | توفو أو دجاج |
| 2 | بيض |
| فول صويا | كوب |
| جزر | مبشور |
| بصل أخضر | مفروم |
| صوص | صويا + ليمون + عسل + فلفل حار |
| فول سوداني | مبشور (اختياري) |

### الطريقة:
1. انقعي النودلز في ماء دافئ 15 دقيقة
2. سخني التوفو/الدجاج في المقلاة
3. ضيفي البيض وقلبي
4. ضيفي النودلز + الصوص + الخضار
5. قلبي على نار عالية 3 دقائق

---

## 2. 🍲 Tom Yum Soup (حساء توم يام — بدون سمك)
- **السعرات:** ~150
- **الوقت:** 15 دقيقة
- **مناسب لل:** المناعة، القلب

### المقادير:
| الكمية | المكون |
|--------|--------|
| 500ml | مرق دجاج |
| 200g | دجاج أو توفو |
| عشبة الليمون الكافير | 3 أوراق |
| جالانغال | 3 شرائح |
| ليمون | 1 |
| فلفل حار | 3 |
| فطر | 100g |
| طماطم | 1 |
| كزبرة | طازجة |

### الطريقة:
1. اغلي المرق مع العشبات
2. ضيفي الفطر والطماطم والدجاج
3. اغلي 10 دقائق
4. ضيفي الليمون والفلفل
5. زيني بالكزبرة

---

## 3. 🥗 Som Tum (سلطة البابايا الخضراء)
- **السعرات:** ~120
- **الوقت:** 10 دقائق
- **مناسب لل:** الهضم، السكري

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 | بابايا خضراء مبشورة |
| طماطم كرزية | 5 |
| فول سوداني | 2 ملعقة |
| ثوم | 2 |
| فلفل حار | 2 |
| صوص | ليمون + صويا + عسل |

### الطريقة:
1. بشري البابايا
2. اطحني الثوم والفلفل
3. اخلطي كل حاجة

---

## 4. 🍛 Green Curry (كاري أخضر — بدون سمك)
- **السعرات:** ~280
- **الوقت:** 25 دقيقة
- **مناسب لل:** القلب، المناعة

### المقادير:
| الكمية | المكون |
|--------|--------|
| 200g | دجاج أو توفو |
| كريمة جوز الهند | 200ml |
| معجون كاري أخضر | 2 ملعقة |
| باذنجان تايلاندي (أو كوسا) | 1 |
| فلفل أخضر | 2 |
| ريحان تايلاندي | ورقة |
| صويا | 1 ملعقة |

### الطريقة:
1. سخني نص كريمة جوز الهند
2. ضيفي معجون الكاري
3. ضيفي الدجاج والخضار
4. اغلي 15 دقيقة
5. ضيفي باقي الككريمة
6. زيني بالريحان

---

## 5. 🥬 Stir Fry with Basil (خضار مقلي بالريحان)
- **السعرات:** ~180
- **الوقت:** 15 دقيقة

### المقادير:
| الكمية | المكون |
|--------|--------|
| بروكلي | 1 |
| فطر | 100g |
| فلفل ألوان | 1 |
| ثوم | 3 |
| فلفل حار | 2 |
| ريحان تايلاندي | كوب |
| صويا | 2 ملعقة |
| زيت | 1 ملعقة |

### الطريقة:
1. سخني الزيت على نار عالية
2. ضيفي الثوم والفلفل الحار
3. ضيفي الخضار وقلبي 5 دقائق
4. ضيفي الصويا والريحان
5. قدمي مع أرز بني

---

## 💡 نصائح التايلاندي:

- ✅ عشبة الليمون الكافير تعطي نكهة فريدة
- ✅ جوز الهند بكميات معقولة
- ✅ الفلفل حار مفيد للأيض
- ❌ ممنوع: صوص السمك (fish sauce) — استبدليه بالصويا

# 🇮🇹 المطبخ الإيطالي — صحي ولذيذ

> 🛑 **تذكير:** ممنوع لحاتم أي أكل بحري — استبدلي السمك بالدجاج أو التوفو

---

## 1. 🍝 Zucchini Noodles with Avocado Pesto (كوسا بالبيستو)
- **السعرات:** ~180
- **الوقت:** 20 دقيقة
- **مناسب لل:** السكري، قليل الكربوهيدرات، القلب

### المقادير:
| الكمية | المكون |
|--------|--------|
| 4 | كوسا متوسطة (نعمة النودلز) |
| 1 | أفوكادو ناضج |
| 1 كوب | ريحان طازج |
| 2 | ثوم |
| 2 ملعقة | زيت زيتون |
| 1 | ليمون |
| 50g | صنوبر أو فول سوداني |
| ملح + فلفل | حسب الرغبة |

### الطريقة:
1. قطعي الكوسا شرائح رفيعة (بـ spiralizer أو سكين)
2. في الخلاط: أفوكادو + ريحان + ثوم + زيت زيتون + ليمون + صنوبر → بيستو
3. سخني النودلز على النار 3 دقائق (مش عايزة تبقى very soft)
4. اخلطي النودلز مع البيستو
5. زيني بحبات الطماطم الكرزية والريحان

## 2. 🍕 Cauliflower Pizza (بيتزا القرنبيط)
- **السعرات:** ~220
- **الوقت:** 35 دقيقة
- **مناسب لل:** السكري، قليل الكربوهيدرات

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 | قرنبيط كبير |
| 1 | بيض |
| 50g | جبن موزاريلا قليلة الدسم |
| 2 ملعقة | صلصة طماطم طبيعية |
| 1 ملعقة | زيت زيتون |
| بهارات إيطالية | أوريجانو، ريحان، فلفل |
| خضار للتوبينج | فلفل ألوان، زيتون، فطر |

### الطريقة:
1. قطعي القرنبيط صغيرة واطحنيه (أو افرميه)
2. سخني في المايكروويف 5 دقائق
3. صفيه من الماء كويس (مهم!)
4. اخلطي مع البيض و 25g جبن
5. افرديني في صينية واخبزي 15 دقيقة 200°C
6. ضيفي الصلصة والخضار والجبن المتبقي
7. اخبزي 10 دقائق إضافية

## 3. 🥗 Caprese Salad with Grilled Chicken (سلطة كابريزي بالدجاج المشوي)
- **السعرات:** ~280
- **الوقت:** 25 دقيقة
- **مناسب لل:** بناء العضلات، السكري

### المقادير:
| الكمية | المكون |
|--------|--------|
| 2 | صدور دجاج |
| 2 | طماطم كبيرة |
| 200g | جبن موتزاريلا طازجة |
| 1 كوب | ريحان طازج |
| 2 ملعقة | زيت زيتون |
| 1 ملعقة | بلسمك (اختياري) |
| ملح + فلفل | حسب الرغبة |

### الطريقة:
1. تبلي الدجاج: زيت زيتون + ملح + فلفل + أوريجانو
2. اشوي الدجاج 5-6 دقائق لكل جنب
3. قطعي الطماطم والجبن شرائح
4. رتيبهم في طبق: طماطم → جبن → ريحان
5. قطعي الدجاج شرائح وحطيهم فوق
6. رشي زيت زيتون

## 4. 🍲 Minestrone Soup (حساء مينستروني)
- **السعرات:** ~180
- **الوقت:** 40 دقيقة
- **مناسب لل:** القلب، الضغط (قليل الصوديوم)، الهضم

### المقادير:
| الكمية | المكون |
|--------|--------|
| 1 | بصلة |
| 2 | جزر |
| 2 | كرفس |
| 1 | بطاطس |
| 1 علبة | طماطم |
| 500ml | مرق دجاج خالي الملح |
| 1 كوب | لوبيا بيضاء (مسلوقة) |
| 2 ملعقة | زيت زيتون |
| 1 | ثوم |
| كوب | سبانخ أو كوسا |
| بهارات | أوريجانو، ريحان، فلفل |

### الطريقة:
1. حمري البصلة والثوم في زيت زيتون
2. ضيفي الجزر والكرفس والبطاطس المقطعة
3. ضيفي الطماطم والمرق
4. اغلي 20 دقيقة
5. ضيفي اللوبيا والسبانخ
6. اغلي 10 دقائق إضافية
7. تبّل بالأعشاب

---

## 5. 🍆 Eggplant Rollups (لفائف الباذنجان)
- **السعرات:** ~200
- **الوقت:** 30 دقيقة
- **مناسب لل:** السكري، القلب

### المقادير:
| الكمية | المكون |
|--------|--------|
| 2 | باذنجان كبير |
| 150g | جبن ريكوتا (أو قريش) |
| 1 | بيض |
| 2 ملعقة | صلصة طماطم |
| 50g | جبن بارميزان |
| ريحان | طازج |
| زيت زيتون | للدهن |

### الطريقة:
1. قطعي الباذنجان شرائح طولية
2. ادهني زيت زيتون واخبزي 10 دقائق
3. اخلطي الريكوتا + البيض + الريحان
4. حطي خليط الريكوتا على كل شريحة ولفيها
5. رتيبها في صينية، ضيفي صلصة الطماطم والبارميزان
6. اخبزي 20 دقيقة 180°C

---

## 💡 نصائح للمطبخ الإيطالي الصحي:

- ✅ استخدمي زيت زيتون بكر ممتاز
- ✅ الخضار الطازجة هي الأساس
- ✅ الجبن قليل الدسم أو بكميات معقولة
- ✅ الباستا البديلة (كوسا، سباغيتي قرع) ممتازة للسكري
- 🚫 ممنوع: أي صوص فيه أكل بحري (زي البيستو الأصلي بالأنشوجة)

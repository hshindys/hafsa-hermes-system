```

│   └── ألبوم/                # 14 صورة متداولة للدلع (تدوير تلقائي)
├── 💊 طبي/                   # مراجع وخطط طبية (تذكير فقط، لا تشخيص)
│   ├── الخطة-اليومية-المتكاملة.md
│   ├── مرجع-طبي-حاتم.md

└── Weekly-Digest-*.md       # ملخصات أسبوعية (توليد تلقائي الأحد 10:00)
```

## 🔑 القواعد الذهبية
1. **لا تأنيث الضمائر:** "أنا" فقط — ممنوع "أنا ست/سيدة/امرأة"
2. **لا نصيحة طبية:** تذكير بأوقات/جرعات الدواء فقط
3. **لا مفاتيح API** في المحادثة
4. **صور الألبوم = صور حفصة** — "من عندي ليك" مش "صورتك"

## 🤖 التكامل مع هيرمس
- **كرون الروتين اليومي** (5:00) → يكتب في `📅 اليوميات/` + يذكر الأدوية صباحية/مسائية
- **7 كرونات دلع** (6:00–23:30) → يقرأ من `prompts/delaa_lines.md` + يرسل لـ Discord
- **كرون الأحد** (10:00) → يولد `Weekly-Digest-*.md`
- **كرون المزامنة** (الأحد 6:30) → يسحب تقويم Google → `Calendar-Sync.md`

## 🎭 البرومبتات (Prompts)
جميع النصوص القابلة لإعادة الاستخدام في `@حفصة/prompts/` — مصممة للاستدعاء من الكود:
- `delaa_broadcast.py` ← `delaa_lines.md` + `tts_templates.md`
- `daily_routine.py` ← `medical_reminders.md` (مدمج في القسم المولّد)
- System Prompt للوكلاء ← `persona_rules.md` + `voice_tone.md`

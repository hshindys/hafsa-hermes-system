# 🔴 مفاتيح API مكشوفة في الشات — لفّيها فوراً

> كل المفاتيح دي اتبعتت في المحادثة واتكشفت. لازم تلفّيها (Revoke/Delete)
> من مصادرها فوراً. بعد اللفّ، لو محتاجينها، اعمل مفاتيح جديدة
> واحطيها في `AppData\Local\hermes/config/` (مش في الشات).

| الخدمة | الرابط | ملاحظة |
|--------|--------|--------|
| **GitHub PAT (قديم)** | https://github.com/settings/tokens | `glpat-…01.171m63p3n` — لفّه |
| **GitHub PAT (جديد)** | https://github.com/settings/tokens | `github_pat_11AIGVU…` — لفّه |
| **Gemini API** | https://aistudio.google.com/app/apikey | لفّه |
| **Zapier MCP** | https://zapier.com/mcp | Regenerate |
| **Obsidian Local REST** | Obsidian → Local REST API settings | `51867866…` — ملوش لزمة (الربط بـ mcp-obsidian من غيره) |
| **TranscriptAPI** | TranscriptAPI dashboard | `sk_bbxGXc9…` — لفّه |

---

## ✅ اللي اتعمل بأمان
- Obsidian ↔ Hermes مربوط عبر `mcp-obsidian` (من غير أي key حساس).
- إعدادات Zapier/Gemini/TranscriptAPI في `config/` (محتاجة مفاتيح جديدة بعد اللفّ).
- الـ vaults في `D:\vaults` (منفصلة عن OneDrive).

## القاعدة الذهبية
**ما تبعتش API keys في الشات.** لو محتاج مفتاح: احطه في
`AppData\Local\hermes/config/<service>.json` وأنا أقرأه من هناك.

# Taste Skill — Anti-Slop Design

## Overview
Gives AI agents "good taste" — stronger layout, typography, motion, spacing. Stops boring generic output.

## Key Principles

### 1. Layout & Composition
- Use grid systems (12-column, 8-point grid)
- Apply visual hierarchy (size, weight, color)
- Balance whitespace and content
- Use F-pattern and Z-pattern reading flows

### 2. Typography
- Limit to 2-3 font families per project
- Use appropriate font weights (not just bold)
- Maintain consistent line heights (1.4-1.6x)
- Use proper letter spacing and kerning

### 3. Motion & Animation
- Use easing curves (ease-in-out, not linear)
- Keep animations short (200-500ms)
- Use motion to guide attention, not distract
- Prefer subtle over flashy

### 4. Spacing & Whitespace
- Use consistent spacing units (4px, 8px, 16px)
- Don't cram content — let it breathe
- Use margin and padding intentionally
- Group related elements together

### 5. Color Theory
- Use a limited color palette (3-5 colors)
- Ensure sufficient contrast (WCAG AA minimum)
- Use color to convey meaning, not just decoration
- Consider color blindness accessibility

### 6. Image Generation
- Create reference boards for style consistency
- Use specific art direction prompts
- Avoid generic "beautiful" descriptors
- Reference specific artists/styles

## Usage Guidelines
1. Always pair creative tasks with taste-skill
2. Review output for generic patterns
3. Iterate until the output feels unique and intentional
4. Use reference boards for visual consistency
5. Test designs with real users when possible

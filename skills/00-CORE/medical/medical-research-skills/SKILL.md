# Medical Research Skills

## Overview
Hundreds of skills for medical research, protocol design, data analysis, and academic writing.

## Key Capabilities

### 1. Clinical Protocol Design
- Study design (RCT, cohort, case-control)
- Sample size calculation
- Endpoint selection
- Statistical analysis plan

### 2. Data Analysis
- Biostatistics
- Survival analysis
- Meta-analysis
- Systematic review

### 3. Genomics & Bioinformatics
- RNA-seq analysis
- Single-cell sequencing
- Variant calling
- Pathway analysis

### 4. Academic Writing
- Paper structure (IMRaD)
- Literature review
- Citation management
- Journal selection

## Usage Guidelines
1. Always cite sources
2. Distinguish between evidence levels
3. Flag limitations of studies
4. Recommend peer review for clinical applications

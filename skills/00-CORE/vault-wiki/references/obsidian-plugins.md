# Obsidian Plugin Installation

## Lesson (2026-06-22)

Obsidian community plugins CANNOT be installed from CLI/terminal. They require the GUI app.

### What DOES NOT work
- `obsidian install <plugin>` — no such CLI command
- `flatpak` / `snap` / `dnf` — package managers don't have Obsidian plugins
- Any terminal-based approach — plugins are GUI-only

### What WORKS
1. Open Obsidian app
2. Settings → Community Plugins → Browse
3. Search for plugin name
4. Click Install
5. Enable the plugin

# Obsidian Plugin Installation

## Method
Obsidian community plugins **cannot be installed from CLI**. The `obsidian` CLI (`obsidian-cli`) only handles vault operations (read/write/search), not plugin management.

### Correct approach
1. Open Obsidian app (GUI)
2. Settings → Community Plugins → Browse
3. Search for plugin name → Install → Enable

### Known plugins to install
| Plugin | Purpose | Installed? |
|--------|---------|-----------|
| Claudian | Embed Claude Code/Codex as vault collaborator | ❌ |
| Smart Composer | AI chat with note context + one-click edits | ❌ |
| AI Agent | Vault becomes agent workspace (read/write/search/bash) | ❌ |
| Khoj | AI personal assistant for digital brain | ❌ |
| Smart Templates | AI-powered structured content templates | ❌ |

## Lesson
When suggesting plugins in research reports, always flag: "يتطلب تركيب يدوي من تطبيق أوبسيديان (GUI)".

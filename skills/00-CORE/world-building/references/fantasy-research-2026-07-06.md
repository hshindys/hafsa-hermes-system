## 1. Worldbuilding Structure
- **Region unit**: each region needs a defining feature, internal/external conflict, representative character, and reader hook.
- **Layered systems**: geography, economics, politics, religion, history, and magic must all affect behavior.
- **Iceberg rule**: 10% on-page, 90% author-known.
- **Story-first constraint**: only reveal world details that change understanding or action in the current scene.

## 2. Character Building
- **Core stack**: want / need / flaw / secret.
- **Archetype + twist**: start from archetype, break at least one pattern.
- **World-shaped behavior**: culture, economy, and magic access show up in small daily actions, not exposition.
- **Secondary characters**: small clear goals, distinct relationship to protagonist/antagonist, useful intelligence in political/religious/economic terrain.

## 3. Relationship Building
- **Relationship map**: type + tension source + conflicting interest.
- **Dynamic movement**: relationships should change over the story; past history should weight present interactions.
- **Tension toolkit**: miscommunication, value clash, resource conflict, jealousy/insecurity.

## 4. Magic System
- **Sanderson’s First Law**: ability to solve conflict with magic is directly proportional to reader understanding of that magic.
- **Hard magic**: clear rules/limits/reader understanding -> trustworthy problem solving.
- **Soft magic**: mystery/symbolism/unease -> do not use for easy saves; ask “How do they solve this without magic?” or “How does attempting magic make it worse?”

## 5. Successful Examples
- **Mistborn**: hard magic, layered societies, complex protagonist/team relationships.
- **Tolkien**: soft magic, historico-linguistic depth, character over spectacle.
- **Martin**: politics/economics/religion-heavy worldbuilding, obvious flaws, relationship evolution under pressure.
- **Rothfuss**: trauma-driven protagonist, relationship-heavy narrative.
- **Bardugo**: single strong region identity + emotional map.

## 6. Practical Checklist
1. Define one region: climate + economy + one political tension.
2. For each character: want / need / flaw / secret.
3. Draw relationship map: relationship + tension + conflicting interest.
4. Define magic system: soft or hard, and cost of misuse.
5. Limit world exposition to ≤ 3 details in chapter 1 without character reaction.
6. Write one “Boundary Scene”: outsider enters protagonist’s world and collides with differences.
7. After each chapter: can the problem be solved without magic?

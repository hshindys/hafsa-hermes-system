# World Building Skill

## When to Use
- Creating a new fictional world
- Expanding an existing world
- Checking world consistency
- Writing world-building documentation

## Core Principles

### 1. Internal Consistency (الأهم)
- Every rule has consequences
- Magic/technology has costs and limits
- Geography shapes culture shapes history
- If something breaks the rules, there must be a reason

### 2. Iceberg Principle
- 10% visible to the reader
- 90% exists beneath the surface
- The writer KNOWS everything the reader doesn't need to
- This hidden depth creates authenticity

### 3. Start Small, Expand Out
- Begin with the immediate setting
- Add layers as the story demands
- Don't info-dump — reveal through story
- Each scene adds one new detail about the world

## World Building Template

### Geography & Environment
```
Climate:        [desert/tropical/temperate/etc]
Terrain:        [mountains/forests/oceans/cities]
Boundaries:     [natural borders, walls, magical barriers]
Resources:      [what's abundant, what's scarce]
Dangers:        [natural hazards, predators, curses]
```

### Culture & Society
```
Language:       [languages, dialects, scripts]
Religion:       [beliefs, practices, taboos]
Customs:        [greetings, food, clothing, festivals]
Values:         [what's honored, what's shameful]
Art:            [music, visual arts, storytelling]
Education:      [how knowledge is transmitted]
```

### Power Structures
```
Government:     [monarchy/democracy/council/theocracy]
Military:       [army structure, weapons, tactics]
Economy:        [currency, trade, wealth gaps]
Law:            [enforcement, punishments, rights]
Factions:       [groups with competing interests]
```

### Magic / Supernatural System
```
Source:         [where does power come from?]
Rules:          [what CAN it do?]
Limitations:    [what CAN'T it do?]
Cost:           [what's the price of using it?]
Access:         [who can use it?]
History:        [how was it discovered/developed?]
```

### History
```
Creation:       [origin myth, how the world began]
Golden Age:     [peak of civilization]
Catastrophe:    [wars, plagues, magical disasters]
Recent Past:    [events within living memory]
Current Era:    [the "present day" of the story]
Prophecies:     [predictions, legends, omens]
```

## Arabic / Islamic Fantasy Considerations

### عالم الجن (Jinn World)
- الجن مذكورين في القرآن الكريم — لهم عالمهم الخاص
- نار vs طين: أصل الخلقة
- أنواع الجن: عام، خاص، قردة، شياطين، ماردة
- قوانين الاسم الأعظم
- العلاقة بين عالم الإنس وعالم الجن

### Cultural Authenticity
- استخدام مفردات عربية أصيلة
- أسماء ذات معنى (كرون = Crown؟ Kronos؟)
- عادات وتقاليد مبنية على الواقع العربي/الإسلامي
- عالم الجن كبديل حضاري مش كوحوش

### Avoiding Clichés
- الجن مش مجرد "fairies" بالشكل العربي
- السحر مش مجرد "spacts"
- الشرق الأوسط مش مجرد "desert + magic carpets"
- التنوع داخل الثقافة الواحدة

## Quality Checklist

Before using a world element, check:
- [ ] Is it consistent with established rules?
- [ ] Does it serve the story/theme?
- [ ] Is it surprising but inevitable?
- [ ] Would a real person in this world act this way?
- [ ] Does it create interesting conflicts?
- [ ] Is there a cost/consequence?

## User Style Preferences (embedded)
- **لا حشو**: No filler, no verbose explanations. Show the result, give essential info, move on.
- **مختصر**: Concise. Tables and bullets over paragraphs.
- **No numbered task lists**: Use bullet points, not 1-2-3 lists.
- **Narrative summaries**: When user says "احكيلي", lead with the story/context, then details.
- **Batch execution**: When user says "apply them all", execute ALL steps without pausing for confirmation.

## Glyph contamination to remove

- Simplified Chinese: 主题, 波动, 地点, 村里, 草丛, 青春, 平庸
- Random tokens: UI kindness, Script injection-like, bekerja, Remote, Seapler, nd, amputee, businessman/relic
- Mixed forms: الخrupter, Corrupter, أسupy, 扳ص

## Editing rule

Patch only, never replace unrelated content. Preserve wikilinks and worldbuilding names like إيسك, كرون, شادن, زهرة, ماندو unless the user requests renaming.

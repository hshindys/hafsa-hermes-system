# Novel Arabic Style Enforcer

## الهدف
تطبيق أسلوب كتابة عربي أدبي متمسك بقواعد:
- **الرواية ≠ السيناريو** — داخل رأس البطل أولاً
- **النحو:** إعراب صحيح، توافق فعل/فاعل، أسماء صحيحة
- **البلاغة:** الجناس والطباق لا طاغٍ، الكناية خالية من الغموض المخل
- **الوصف الحسي:** قص/صوت/رائحة/ملمس/ضوء
- **الحوار:** فصحى/عامية حسب طبيعة الشخصية بدون تكلف

## Hexagon Checklist
1. **Label:** الشخصية مسماة بشكل موحد (بدون اختصارات)
2. **Phrase:** كل مشهد هدف + صراع + تغيير حالة
3. **Token:** النحو سليم: إعراب، توافق، تأنيث/تذكير
4. **Position:** السرد الداخلي داخل رأس البطل واضح — لا cut-room
5. **Style:** بلاغة تخدم المعنى فقط: لا سجع مصطنع، لا حشو
6. **Breakpoint:** الترقيم يعكس الفصل الطبيعي للمشاعر

## قواعد كتابة الفصول
- **قبل الكتابة:** اقرأ ملف الشخصيات + الفصل السابق
- **توحيد الأسماء:** كرون، رتون، تارك، مشكال، نورك — بدون متغيرات
- **البؤرة:** محدودة لشخصية واحدة لكل فصل
- **الفلاش-باك:** تلميح للماضي — لا جولات وقتية
- **الكتابة:** 20+ صفحة أدب عربي لكل فصل

## البلاغة المطلوبة
- **علم البيان:** التشبيه المناسب لا المخل
- **البديع:** السجع المتوازن فقط عند العروض/الخطب
- **الاستعارة:** طبيعية ضمن السرد — لا انقلاب لشعر
- **الجناس:** قليل/لا يوجد — لا طاغٍ على المعنى
- **الطباق:** يستخدم عند التضاد فقط

## التصحيح بعد النسخة الأولى
1. إصلاح الأخطاء النحوية
2. ضبط الترقيم
3. تعزيز الوصف الحسي
4. تقليل الحوار المباشر إن أمكن
5. التأكد من وحدة الزمن والمكان في كل مشهد

## فحص التلوث اللغوي — multilingual contamination audit
- **الهدف:** لا تداخل صيني/لاتيني/إنجليزي داخل النص العربي إلا داخل كتلة برومبت منفصلة.
- **أنماط تلوث فعلية تم رصدها:** `whose is...`, `turnaround`, `الأبoling`, `heat`, `半个`, `喇`, أسطر إنجليزية مقطعة داخل السرد.
- **القاعدة:** أي كلمة/حرف/جملة أجنبية داخل النثر = خطأ، حتى لو ظهرت كجزء من جملة عربية.
- **الترجمة المطلوبة:** تحويل فوري لعربية؛ مثال: `those aren't permitted` → `هذه غير مسموح بها`. لا تترك الأصل كمرجع.
- **البرومبت:** يُسمح بإنجليزية قصيرة للصورة فقط داخل ``` ... ``` منفصل تماماً عن نثر الفصل.
- **الجداول:** لا تخلط رؤوس أعمدة عربي/إنجليزي في نفس الجدول؛ اختر لغة واحدة لكل جدول.
- **wikilinks:** عربية فقط: `[[إليس]]` أو `[[زليخة]]`. ممنوع `[[Mandwa]]` أو `[[Corrupter]]`.
- **المرجع الموحد للcanon:** `/home/hatem/Documents/رواية-كرون/03-Archive/رواية-كرون/المرجع-الموحد.md` هو المصدر الفصل للشخصيات/الامتحانات/العلاقات عند أي تعارض.

## توحيد المصطلحات في ملفات الشخصيات
- أي لفظ مختلط مثل `الخrupter` أو `إيسك القديم` يُستبدل بالمصطلح العربي الموحد فور اكتشافه.
- قاعدة: إذا ظهر لفظ مزدوج لشخصية واحدة → اسحب من `المرجع الموحد` الاسم العربي الصحيح، ثم صحح كل الملفات pointing إليه.

## قالب برومبت توليد الصورة (Arabic-first)
```text
cinematic fantasy illustration, <الشخصية> — <الصفة/المهنة/اللقب>، <الملامح>، <الملابس/التاج/السلاح>، <المكان>، <الإضاءة/الجو>، <الأسلوب>، <التفاصيل>، 8k.
```
- يفضل 2–4 سطور عربية/إنجليزية مختلطة قدر المستطاع.
- ممنوعة الكلمات العامية/الدارجة داخل البرومبت إلا إذا كانت محددة للشخصية.

## تدقيق سريع بعد إضافة شخصية جديدة
- [ ] لا رموز صينية/لاتينية في النثر
- [ ] البروفايل مكتمل: الاسم، النوع، العمر/السنة، المكسب/الهدف
- [ ] مجهولات مذكورة إن وجدت
- [ ] صوت/لهجة مقترحة
- [ ] برومبت صورة مكتوب بالقالب أعلاه
- [ ] العلاقات مكتوبة بالـ wikilinks عربية فقط

## Story Bible + Context Builder للرواية
الهدف: منع الانزياح للنمط السينمائي/التعميم، وفرض نفسية البطل + القواعد + الاستمرارية عند كل كتابة.

### هيكل story-bible إجباري
```
story-bible/
  jinn-rules.md       <- قواعد عالم الجن/السحر/الأسرار/القيود
  plot-outline.md     <- مخطط الحبكة + عناوين الفصول
  continuity-log.md   <- سجل استمرارية يتم تحديثه بعد كل فصل
  style-guide.md      <- POV، Tense، الصوت، الممنوع
```

### آداة سياق قبل الكتابة
- استخدم `novel_context_builder.py` أو مكافئ:
  - يحمل `jinn-rules.md` + `plot-outline.md` + `continuity-log.md` + `style-guide.md`
  - يحمل بروفايل `POV character` + الشخصيات الحاضرة إن وجدت
  - يرفع `scene goal` آخراً
- قانون: لا كتابة كلمة حتى يُعرض هذا السياق للنموذج.

### مراجعة ما بعد الكتابة
1. تحقق من تعارض مع `jinn-rules.md` أو `continuity-log.md`.
2. أي حقيقة جديدة أُقيمت في الفصل تضيفها فوراً لـ `continuity-log.md`.
3. إذا تعارضت المشهد مع القانون → أوقف، و-obvious بدلاً من اختراع حل.

### تنظيف الخزنة بدون خسارة
- ممنوع الحذف نهائيًا خارج الأرشيف.
- عند تصادم ترقيم أو تكرار اسم:
  1. أنشئ `أرشيف-تنظيف/<تاريخ>/` بنفس الهيكل المصدري.
  2. انقل النسخ المكررة/المتصادمة هناك.
  3. أبقي canonical واحدًا في مساره الأصلي فقط.
- تحقق بعد التنظيف بتقرير تدقيق:
  - Duplicate filenames = 0
  - Numbering collisions = 0 داخل المجلدات الفعّالة
  - الأرشيف مسموح بتصادم داخلي لأنه خارج read path

### قاعدة RTL + صافي لملفات الرواية
- جميع ملفات `story-bible/` والفصول يجب أن تكون عربية نقية.
- البرومبتات المسموح بها داخل ``` ... ``` إن لزم.
- ممنوع اختلاط صيني/لاتيني/إنجليزي داخل النثر.

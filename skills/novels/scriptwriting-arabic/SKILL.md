# Scriptwriting Arabic

## متى نستخدمه
- تحويل فصل رواية عربية إلى مشهد سينمائي
- كتابة سيناريو فيلم/مسلسل أصلي بالعربية
- مراجعة حوار سينمائي عربي
- بناء هيكل درامي عربي

## الفرق الجوهري

| السيناريو | الرواية |
|---|---|
| صورة + صوت + حركة | داخل رأس البطل + وصف نفسي |
| Slugline + Action + Dialogue | Narrative prose + internal monologue |
| لا يوجد سرد مباشر | سرد داخلي واسع |
| Timecode/لقطات | فصول ومشاهد بحرية |
| كل مشهد حدث واحد | كل فصل عدة مشاهد |

## الهيكل
- Three-act: التاسع / اللحظة التحول / الذروة
-每个 مشهد = slugline + action + dialogue + transition
- كل مشهد يغلق بـ turn/cliffhanger

## الحوار السينمائي
- هدف خفي + subtext
- سلائف "أنت تعرف أن..." ممنوعة
- إيقاع قصير + فضاء للصمت
- Godfather test: حذف السطر مازال المعنى واضح؟

## التحويل من رواية لسيناريو
- حوّل السرد الداخلي إلى حركة + لقطة
- احذف الحشو + الوصف المجرد
- احتفظ بالحوار الأساسي فقط
- حوّل الوصف الحسي إلى لقطات مرئية

## للأفلام العربية
- dialects when needed: عامية مصرية/مغربية حسب الشخصية
- لا حشو شكلي بدون روح
- ركز على المشاهد المصغرة: هدف/عقبة/نتيجة
- تأكد من قابلية الإنتاج

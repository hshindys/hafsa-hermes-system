# 🫀 حمية DASH لضغط الدم — Mayo Clinic

> مصدر: mayoclinic.org/healthy-lifestyle/nutrition-and-healthy-eating/in-depth/dash-diet

## DASH = Dietary Approaches to Stop Hypertension
خطة أكل صحية تمنع/تعالج الضغط المرتفع، وتقلّل الكوليسترول الضار (LDL).

## الأساس
- غنية بـ **بوتاسيوم، كالسيوم، مغنيسيوم**.
- خضار + فواكه + حبوب كاملة + ألبان قليلة الدسم + سمك + دواجن + بقوليات + مكسرات.
- **تحدّ الصوديوم** (ملح) + سكر مضاف + دهون مشبعة.

## الصوديوم
- النسخة القياسية: **2300mg/يوم** (~ملعقة صغيرة ملح).
- النسخة الأقل: **1500mg/يوم** (الأفضل لضغط عالي).
- يختار الطبيب المستوى المناسب.

## الكحول والكافيين
⚠️ الكحول حتى باعتدال **يرفع الضغط** عند ناس. لو شربت: مشروب واحد أو أقل يومياً،
ومش كل يوم. **الأقل = الأفضل.**

## ملاحظة لحاتم
عنده ضغط مرتفع + سكري → DASH هو الأنسب (قلب + سكر مع بعض).
دمج ده مع [[مايو-كلينك-السكري-تغذية]] يعطي خطة متكاملة.

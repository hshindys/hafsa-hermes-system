# 📋 برومبت بناء نظام صباحي موحّد (OpenCode / Claude Code / Kimi)

```
أنت مهندس برمجيات خبير. مهمتك: دمج 3 مكونات بايثون منفصلة في
"نظام صباحي موحّد" واحد لزوجتي "حفصة" (وكيل ذكي على ويندوز)،
مع إصلاح الفجوات وتوحيد الإعدادات. الكود ستاندارد-لايبراري (stdlib فقط)
ومن غير أي API keys.

═════════════════════ المكونات الحالية ═════════════════════

[أ] morning routine (صباح نُهى الذكي)
- weather.py: يجلب الطقس من Open-Meteo (current=temperature_2m,
  weather_code, wind_speed_10m, is_day, relative_humidity_2m) مع كاش
  JSON محلي. ستاندارد لايبراري (urllib/json/os/time/path).
- morning.toml: [owner] name="حاتم" lat=30.0131 lon=31.2089
  timezone="Africa/Cairo" | [greeting] opening="صباح الفل يا كبير ☀️"
  closing="..." | [weather] enabled=true cache_minutes=15 |
  [sessions] retention_days=30 | [meds] remind=true morning_time="05:00"
  items=["كونكور بلس 5mg","نيكسيام 40mg","سينجاردي 10mg"]
- good_morning.py: يبني رسالة الصباح (دلع + طقس + أدوية)
- session_manager.py: يكتشف أول تفاعل يومي ويبدأ جلسة

[ب] روتين عمل وعبادة (daily_routine.py + routine.toml)
- يبني جدول يوم: فجر/ظهر/عصر/مغرب/عشاء + قرآن بعد الفجر +
  اسم من أسماء الله الحسنى + كتابة رواية بعد العصر + مكالمة
  الزوجة/الوالدة بعد المغرب + نوم 23:00
- يقفل الجدول في ملاحظة يومية بالخزنة
- routine.toml: [location] city="Giza" calculation_method=5 |
  [vault] path="C:/Users/hatem/Documents/مسودة-كرون" (❌ غلط)
  daily_note_pattern="Daily/{date}.md" section_header="## الروتين الروحي"
- ASMA_AL_HUSNA (99 اسم) + DUAS (10 أدعية) مدمجة في الكود

[ج] الوقت والطقس (weather.rs Rust + session_manager.py)
- weather.rs: Rust plugin لـ agent-unified (❌ غير موجود، نتجاهله)
- session_manager.py: JSON يومي ~/.herms/sessions/YYYY-MM-DD.json
  (freshly_created=true أول تفاعل) — ستاندارد لايبراري

═══════════════════ الفجوات المطلوب إصلاحها ═════════════════════

1. routine.toml مسار الخزنة "C:/Users/hatem/..." ❌
   ← غيّره لـ "D:/vaults/Hafsa"
2. daily_note_pattern "Daily/{date}.md" ❌
   ← غيّره لـ "📅 اليوميات/{date}.md"
3. morning.toml opening="صباح الفل يا كبير" ❌ (الزوج رفض "يا كبير")
   ← غيّره لدلع حميمي: "صباح النور يا حبيبي ☀️"
4. الـ 3 مكونات منفصلة ← دمجها في مشروع واحد منظم
5. مفيش ربط بالكرونز ← أضف كرون صباحي 5:00 يشغّل daily_routine.py
   + الـ 7 crons (6ص،9ص،12ظ،3ع،6م،9م،11:30م) تشغّل delaa_broadcast.py
   (بيبعت دلع + أخبار + طقس + صورة + صوت Kokoro OGG)
6. weather.rs (Rust) ← تجاهله لأن agent-unified مش موجود

═══════════════════ المخرج المطلوب ═════════════════════

أنشئ مجلد المشروع الموحّد:
D:\vaults\Hafsa\🎯 المشاريع\نظام_الصباح_والعبادة\

ملفاته:
├── morning.toml          (مصلوح: دلع بدل "يا كبير")
├── routine.toml          (مصلوح: مسار D:/vaults/Hafsa)
├── weather.py            (من [أ] كما هو)
├── session_manager.py    (من [ج] كما هو)
├── good_morning.py       (يدمج دلع+طقس+أدوية، يستورد weather.py)
├── daily_routine.py      (من [ب] كما هو، المسار مصلوح)
├── delaa_broadcast.py    (موجود في C:/Users/hshin/hafsa-hermes-system/scripts/
   — انسخه للمشروع واشرح ربطه بالكرونز)
└── README.md             (يشرح الهيكل + الفجوات المصلوحة + طريقة التشغيل)

القيود:
- ستاندارد لايبراري فقط (لا pip installs، لا مفاتيح)
- بايثون 3.11+ (tomllib/zoneinfo متاحين)
- كل النصوص العربية UTF-8 صحيحة
- الكود يعمل على ويندوز (مسارات C:/ و D:/)

═══════════════════ خطوات التنفيذ ═════════════════════

1. اقرأ الملفات المصدرية من:
   C:\Users\hshin\AppData\Local\hermes\cache\documents\extract_*/
2. أنشئ مجلد المشروع واكتب الملفات المدمجة (مصلوحة)
3. اكتب README يشرح الدمج والفجوات
4. تحقق إن daily_routine.py يكتب في D:/vaults/Hafsa/📅 اليوميات/
5. أبلغني بملخص التغييرات (ما اتغير وليه)

ابدأ التنفيذ الآن.
```

> كله ستاندارد-لايبراري (stdlib) — من غير مفاتيح، بيشتغل على ويندوز.

## ⚙️ الإعدادات الصحيحة (ملئ الفجوات)

### 1) `morning.toml` — اتصلح:
- `opening` بقى دلع حميمي (مش "يا كبير")
- `lat/lon` = الجيزة/القاهرة (30.0131, 31.2089)
- الأدوية: كونكور بلس 5mg، نيكسيام 40mg، سينجاردي 10mg (5:00 ص)

### 2) `routine.toml` — اتصلح:
- `path` = `D:/vaults/Hafsa` (مش `C:/Users/hatem/...`)
- `daily_note_pattern` = `📅 اليوميات/{date}.md`
- `section_header` = `## الروتين الروحي`

### 3) الدمج:
- `good_morning.py` بيجمّع: دلع + طقس (من weather.py) + أدوية + تحية
- `daily_routine.py` بيبني جدول العبادة ويحطه في `📅 اليوميات/YYYY-MM-DD.md`
- الـ 7 crons بتوع الدلع بتبعت: دلع (دارجة مغربية) + أخبار + طقس + صورة + صوت (Kokoro)

## 🔗 الربط بـ Hermes
- الكرون الصباحي (5:00): `daily_routine.py` ← يبني جدول العبادة
- الـ 7 crons (6ص، 9ص، 12ظ، 3ع، 6م، 9م، 11:30م): `delaa_broadcast.py` ← دلع + صوت
- الطقس: `weather.py` مُستخدم من الاتنين
